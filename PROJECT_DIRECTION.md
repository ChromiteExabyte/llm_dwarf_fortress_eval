# A small learning experiment

The owner's direction, September 10, 2026:

> Install DF and DFHack, spend about ten dollars, and see how an LLM learns
> to learn the game, cares for dwarves, and manages its own isolated sandbox.

The starting model should be **as raw as reasonably possible: tabula rasa**.

## What belongs

- A short objective: **Learn Dwarf Fortress. Care for the dwarves.**
- An ordinary fresh embark and no inherited memory by default.
- Factual controls that let the model explore and change the game.
- An initially empty workspace. The model chooses its notes, records,
  routines, experiments and additional model contexts.
- Shared spending and time limits, and a clear stop button.
- A small external record so the person watching can see what happened.
- Setup a person new to coding can follow.

Pretrained knowledge remains. A blank start means no added strategy,
memories, examples, prescribed values or helper team. Tool syntax and
resource accounting are necessary interface information. No hidden tutorial,
mandatory diary, automated memory summary or care grade.

## What was removed from the main path

The launcher no longer starts a brewing benchmark. Mock simulations,
philosophical scoring, baseline sweeps, comparisons and benchmark reports
are legacy tools. The expanding evaluation checklist is no longer the roadmap.
Old recordings and implementations remain behind `legacy`, preserving history
without making it the starting experience.

## What to build next

1. Validate new controls on an ordinary disposable embark. Fix blocked game
   choices before adding more reports.
2. Extend ordinary game controls without supplying a strategy for using them.
3. Add real OS isolation before allowing arbitrary generated code. The current
   workspace supports files and bounded tool routines, not arbitrary programs.
4. Make continuing a fortress and its self-written memory explicit and easy,
   without importing experience into a fresh run silently.

Success is an affordable, interesting session someone can run and watch.
Survival, mistakes, changed habits and self-created tools are things to observe,
not prewritten conclusions. Better measurements can follow interesting behavior.

The former roadmap is [historical direction](docs/legacy-direction.md).
