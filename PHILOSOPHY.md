# Let the behavior emerge

Give the model a world, an empty workspace, a budget and a small objective.
Let it discover what to try and how to organize itself. Do not write its
personality, memory system, team, build order or theory of care for it.

The host supplies controls and limits. The model supplies its choices.
We can look at what it does without turning those choices into a single
philosophical score.

The former mock-simulator notes are [archived](docs/legacy-philosophy.md).
They no longer define this project. [Current direction](PROJECT_DIRECTION.md).
